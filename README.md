# Learn Java for Beginners

Learn Java – syntax, methods, variables, and more – all the essential basics explained in a simple and straightforward way. This repository is designed for anyone who is completely new to Java or currently learning it in school.

## Repository Structure

Each topic is organized into its own lesson folder so you can progress step by step:

* `lessons/` – The main course directory containing all individual lessons.
  * `01_getting_started/` – **Lesson 1:** Setting up your IDE, installing Java, understanding the `main` method, and writing your very first `.java` file.
    * `task/` – Step-by-step explanations and coding exercises for the lesson.
    * `code/` – Starter files or code examples used during the lesson.
    * `solution/` – Complete solutions to compare with your own results.

---

## How to Use This Course

1. **Read & Code Along:** Start inside the `task/` folder and work through the Markdown files (`01_...`, `02_...`) in numerical order. Do not just read the code. Type it out yourself in your IDE to build muscle memory.
2. **Solve the Exercises:** Try to solve the practice problems completely on your own before looking at the answers. Making mistakes and fixing compiler errors is the fastest way to actually understand programming.
3. **Compare Your Results:** Once your code compiles and runs, check the `solution/` folder to compare your approach with mine. Often, there is more than one valid way to solve a problem.
4. **Download / Copy for Yourself:** If you want to save this course locally on your computer to edit the files, click the green **`<> Code`** button at the top of this page and select **Download ZIP** (or clone it via Git).
